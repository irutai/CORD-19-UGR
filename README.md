# CORD-19-UGR
Subset of the CORD-19 dataset (https://www.kaggle.com/datasets/allen-institute-for-ai/CORD-19-research-challenge), where author names are now disambiguatedAuthors restricted with at least 20 publications under their canonical full names. Result: 130,477 articles, 11,070 venues, and 7,387 authors.
